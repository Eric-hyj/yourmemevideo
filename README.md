# YourMemeVideo

**Website: [yourmemevideo.com](https://yourmemevideo.com/)**

YourMemeVideo is an English-language AI meme video project built around individual template pages with clear photo requirements, generation settings, FAQs and usage guides.

## Current status

The three template pages and generation flow have been implemented and tested locally. A restricted website preview has been deployed; production integrations and live verification are still in progress. Google sign-in, paid checkout and new-site generation have not yet completed production acceptance. Checkout and generation remain disabled while verification is underway.

This repository contains public product information only. It does not publish the application implementation or commercial template source code. A website link is not a claim that paid generation is already available.

## Initial templates

| Template | Photo input | Intended output |
| --- | --- | --- |
| [Zombie Couple](https://yourmemevideo.com/templates/zombie-couple-video) | Two separate adult portraits, one for each role | A 15-second fictional warehouse-to-reunion story; landscape or portrait |
| [Tip Toe](https://yourmemevideo.com/templates/tip-toeing-in-my-jordans) | One adult portrait | A 10-second landscape dance scene targeting the reference dancer’s facial identity |
| [Ozil Goal](https://yourmemevideo.com/templates/ozil-goal-video) | One adult photo; full-body input provides more outfit information | A 15-second portrait football sequence with character and visible-outfit replacement |

The implemented options are 480p or 720p and original soundtrack or silent output. Identity, expressions and movement can vary. The templates use ByteDance Seedance 2.0 Mini through KIE; the project is not affiliated with or endorsed by model providers, meme creators or people depicted in reference material.

## Intended generation flow

1. Open a template and review its required photos and examples.
2. Sign in with Google and upload authorized adult photos.
3. Choose the available format, resolution and audio; review the credit charge.
4. Submit once, follow progress in My videos, and review the complete result before downloading.

These steps describe the implemented flow. They are not evidence of completed production verification. Existing product examples are explicitly labelled and are not presented as videos generated on this new site.
